GPS Track Editor Keyboard Shortcuts and Mouse Actions

General

Ctrl + O

Choose a GPS track file on your computer to load

Ctrl + S

Save the active track

Esc

Move the keyboard input focus to the main view

Ctrl + B

Break a track segment in the current point

Ctrl + J

Join two segments that are adjacent to the current point

Main view

Ctrl + M

Toggle map on/off

Arrow keys

Scroll the view in the direction of the arrow

Plus sign (+)

Zoom in the view

Page Down

Mouse wheel forward

Minus sign (-)

Zoom out the view

Page Up

Mouse wheel backward

N

Move the focus to the next point of the active track

Ctrl + Right arrow

P

Move the focus to the previous point of the active track

Ctrl + Left arrow

Drag with the left mouse button

Move the view in the direction you drag the mouse

Double click

Zoom the view in and center it on the clicked point

Tracks

Delete

Delete a segment from the track or remove the track from the list

Enter

Locate the selected item on the main view

Spacebar

Toggle the selected items on/off in the main view

Right / Left arrow

Expand/collapse track tree

Points

Delete

Mark the current track point as invalid

Shift + Delete

Completely remove the current point from the track

Ctrl + Down arrow

Go to the next filtered point subsequence

Ctrl + Up arrow

Go to the previous filtered point subsequence
